# 🧠 IT-Quiz

A fun and interactive Python quiz game testing your knowledge of IT history, programming, and technology concepts!

## ✨ Features

- 6 engaging questions covering IT history and technology
- Real-time score tracking (0-6 points)
- Instant feedback for each answer
- Flexible answer matching (case-insensitive, multiple accepted formats)
- Final congratulations or encouragement message

## 🎯 Quiz Questions

1. **Who was the first programmer in the world?**
   - Answer: Ada Lovelace

2. **Who invented the Python programming language?**
   - Answer: Guido van Rossum

3. **What type of software system does TOTVS develop?**
   - Answer: ERP (Enterprise Resource Planning)

4. **Who is considered the father of Artificial Intelligence?**
   - Answer: Alan Turing

5. **What is the name given to the set of instructions, data or logical programs used to operate computers and devices?**
   - Answer: Software

6. **What is the physical and tangible part of computers and electronic devices?**
   - Answer: Hardware

## 📋 Requirements

- Python 3.x

## 🚀 How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/Theo-Prado/IT-Quiz.git
   cd IT-Quiz
   ```

2. Run the quiz:
   ```bash
   python QUIZ.py
   ```

## 🎮 How to Play

1. Start the quiz by running the script
2. Read each question carefully
3. Type your answer and press Enter
4. Receive instant feedback for each question
5. Track your score as you progress (displayed after each answer)
6. Get your final score and result at the end!

## 🏆 Scoring

- ✅ **6/6**: Congratulations! You won the quiz!
- 📊 **Below 6/6**: Keep learning and try again!

## 📝 Notes

- Answers are **case-insensitive** (uppercase and lowercase accepted)
- Some questions accept **multiple answer formats** for flexibility
- Questions cover IT history, famous programmers, and tech concepts
